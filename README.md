# IM 15 Reef Manager

Private, single-user aquarium parameter tracker for the IM Fusion 15 (10 gallons actual water volume).

## Deployment
Connect this GitHub repository to Cloudflare Pages. Framework preset: None. Build command: leave empty. Output directory: `/`.

## Important
This is a local-storage prototype. It does **not** sync with Google Sheets, Scriptable, or Neptune Apex yet. Do not assume a reading is live. Back up readings using Export CSV before clearing browser data.

Future work: authenticated server-side API, Google Sheets sync, widget refresh, parameter trend charts, and maintenance journal.
